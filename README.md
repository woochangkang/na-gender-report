# na-gender-report

한국 국회의원 성인지감수성 연구(Paper 2) — 자료·변수·기본 모형 분석 보고서.

공개 주소의 `index.html` 은 **StatiCrypt 으로 암호화된 파일**입니다. 비밀번호를
입력하면 브라우저에서 복호화되어 보고서가 열립니다. 저장소에는 암호문만 들어 있습니다.

- 원본 작성: `Korea_NA_Gender/my_project_cm/analysis/report_V0930.qmd` (별도 비공개 저장소)
- 갱신 절차: 원본을 다시 렌더 → `index.html` 로 복사 → StatiCrypt 재적용 → 푸시

## 주의

StatiCrypt 은 **HTML 만** 암호화합니다. 이 저장소에는 데이터 파일(CSV·parquet)을
두지 않습니다. 보고서는 자체완결(standalone) HTML 이라 표·그림이 모두 내장돼 있고
외부 요청이 없습니다.
